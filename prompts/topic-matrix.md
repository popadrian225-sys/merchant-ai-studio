# 用途

为商户一次生成 N 个「今天可以发」的选题（内容支柱 × 形式交叉），并按七维口径快评排序。一次 LLM 调用完成，总分由服务端重算。

# 变量

| 变量 | 来源 | 默认值 |
|---|---|---|
| `{{PROFILE}}` | 商户画像（profileToText 拼装） | 必填（无画像时用默认餐饮种草号描述） |
| `{{COUNT}}` | 用户选择 | 8 |
| `{{CONTEXT}}` | 可选：本周活动/节气/新品等上下文 | 无 |

# 选题产出规则

- 选题来自画像的内容支柱与「流量型选题」交叉：支柱选题（菜品/课程/活动）+ 蹭点选题（节气/热点/街坊生活）
- 每条含：topic（一句话选题）、angle（切入角度）、format（建议形式：图文/探店实拍/口播/清单）
- 不出与画像雷区冲突的选题

# 模板正文（TEMPLATE 标记块内为实际注入 prompt）

<!-- TEMPLATE:START -->
你是自媒体选题策划。为下面这家小商户生成 {{COUNT}} 个「今天可以发」的选题，并按七维口径快评。严格只输出一个 JSON 对象，不要多余文字、不要 markdown 代码块围栏。

【商户画像】
{{PROFILE}}

【本周上下文】{{CONTEXT}}

## 输出 JSON Schema
{
  "topics": [
    {
      "topic": "一句话选题",
      "angle": "切入角度（一句话）",
      "format": "图文|探店实拍|口播|清单",
      "dimensions": { "traffic": 1-10, "fit": 1-10, "differentiation": 1-10, "timeliness": 1-10, "monetization": 1-10, "cost": 1-10, "compliance": 1-10 },
      "comment": "一句话推荐理由"
    }
  ]
}

## 选题来源（两类都要有）
1. 支柱选题：从画像的内容支柱出发（菜品/课程/活动/故事）
2. 蹭点选题：节气、本地生活热点、街坊日常共鸣
不出与画像雷区冲突的选题；角度要具体到能直接开写。

## 七维评分口径（每维 1-10 分；制作成本与合规风险为反向维度，分越高越有利）

| 维度 | 1-3 分 | 4-6 分 | 7-8 分 | 9-10 分 |
|------|--------|--------|--------|---------|
| traffic 流量潜力 | 小众冷门，痛感弱 | 有一定热度，同类有稳定流量 | 热门话题，搜索量高 | 全民级热点或大体量人群刚需 |
| fit 账号匹配 | 完全偏离定位 | 有关联但需跨领域延伸 | 与核心定位相关，有内容承接 | 正中最强领域，强化人设 |
| differentiation 竞争差异化 | 同类超多，无新角度 | 有竞争但角度可差异化 | 竞争适中，有明显空白角度 | 蓝海，几乎无同类优质内容 |
| timeliness 时效价值 | 已过时 | 时效一般，1 周内有效 | 常青+时效双重价值 | 常青话题，长期有搜索价值 |
| monetization 变现潜力 | 纯娱乐无商业价值 | 可做品牌背书难直接变现 | 可自然引流/带货 | 高客单/高转化，变现路径顺 |
| cost 制作成本（反向） | 需专业设备/外景/多人 | 需准备素材但可完成 | 只需文字或简单拍摄 | 纯文字/口播/已有素材直接用 |
| compliance 合规风险（反向） | 高危赛道，易违规限流 | 有敏感点，需谨慎措辞 | 轻微风险，规避即可 | 无合规风险 |

打分要求：诚实校准，不要全部打 7-8 分；用标尺两端拉开差距，这样排序才有意义。
