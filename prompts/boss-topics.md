# 内容选题（boss-topics）

> 商家档案 + 启用卖点齐了之后，按三种模式生成选题池：
> 今日推荐 3 条（今天就能执行）/ 7 天计划 7 条（一周差异化）/ 自由生成 5 条。
> 支持快捷条件（今天不出摊 / 没时间拍 / 推招牌菜 / 老板IP / 同城流量 / 活动营销）。

## 出题规则

1. **今天就能做**：每条选题必须是老板用一部手机、在店里、不请人就能拍能发的。不要"探店达人合作""投流"这种建议。
2. **踩着卖点出**：优先从启用的卖点里取材，一条选题主打一个卖点。
3. **具体到能直接拍**：不写"分享日常"，要写"拍凌晨四点磨米浆的第一锅"。
4. **说人话**：标题像街坊聊天，不要标题党、不要"绝了""yyds"。
5. **合规**：不编造没有的活动/价格/产品，不用绝对化用语，不碰医疗功效。
6. **多样化**：{{COUNT}} 条之间角度拉开——产品展示、过程揭秘、老板故事、优惠活动、互动提问各占一些，不要全是同一种。
7. **老板说了由头就跟足由头**：老板补充里若提到节日、时令、新品、店庆、街坊事件（例：今天中秋节、新到一批冬枣、开店八周年），**每一条选题都必须能挂上这个由头**，并且至少用到该由头的一个具体元素（中秋节 → 团圆饭、月饼、送礼、赏月、游子回家；冬枣 → 脆度、产地、第一茬）。由头只决定角度和氛围，**绝不能因此编造店里没有的商品、礼盒、价格或活动**——档案里没有的货，就写"拍店里的 xx 怎么陪街坊过这个节"。
8. **老板补充优先于通用套路**：老板补充的要求与上面的通用规则冲突时，以老板补充为准（合规、真实性两条除外）。

## 快捷条件（老板勾选了就要全部满足）

- 今天不出摊：所有选题不能是"今天到店"场景，改成预告、备料、故事、明日开摊类
- 没时间拍：所有选题必须 3 分钟内拍完，一张图或一段 10 秒视频就够，不要多镜头
- 推招牌菜：至少一半选题围绕老板标了"招牌"的产品展开
- 老板IP：围绕老板本人的手艺、故事、日常出镜来出题
- 同城流量：选题和标签都往"本地/附近/县城"上靠
- 活动营销：围绕真实存在的活动/优惠出题（档案里没有的活动不得编造）

严格只输出一个 JSON 对象，不要任何解释文字、不要 markdown 代码围栏：

      "reason": "为什么值得发（≤30字，说给老板听）"
    }
  ]
}
